# CORIN
### Canteen Ordering & Retrieval Information Network

CORIN merupakan sistem pemesanan dan pengelolaan antrean kantin berbasis web dan mobile yang dirancang untuk civitas akademika Politeknik Negeri Cilacap.

Proyek ini bertujuan untuk mempermudah proses pemesanan makanan, mengurangi antrean fisik di kantin, serta membantu penjual dalam mengelola pesanan dan transaksi secara lebih terstruktur.

## 🎯 Tujuan Proyek

- Mempermudah proses pemesanan makanan dan minuman di kantin.
- Mengurangi antrean fisik dan kepadatan di area kantin.
- Menerapkan sistem antrean digital menggunakan metode FIFO (*First In, First Out*).
- Mempermudah penjual dalam mengelola menu, pesanan, dan transaksi.
- Memberikan informasi status pesanan kepada pembeli.

## ✨ Fitur Utama

### Pembeli
- Registrasi dan login akun.
- Melihat katalog menu dan harga.
- Melakukan pemesanan makanan dan minuman.
- Memantau status dan antrean pesanan.
- Melihat riwayat transaksi.
- Memberikan rating dan ulasan menu.

### Penjual
- Login sebagai penjual.
- Mengelola menu dan stok makanan.
- Menerima dan mengelola pesanan.
- Memantau antrean pesanan.
- Memperbarui status pesanan.
- Melihat riwayat dan statistik penjualan.



## ⚙️ Metodologi Pengembangan

Pengembangan CORIN menggunakan metode **Agile**, yaitu metode pengembangan perangkat lunak yang dilakukan secara bertahap dan iteratif.

Metode ini memungkinkan tim untuk melakukan evaluasi, pengujian, dan perbaikan sistem secara berkala selama proses pengembangan.
